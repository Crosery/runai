验收建议

  • 每个 mockup 都是 self-contained HTML，双击直接在浏览器打开，无需 server。
  • tab 切换 / toggle 开关 / 主题切换 / 滑块 全部可交互（数据是 mock）。
  • Linear 和 Vercel 有 theme toggle，按你的偏好挑色；HTOP 只有深色（终端调性）。
  • 挑完风格后在 feat/multiuser-server 分支接着把选中的方向落到 web/index.html 实现，web/app.css 全量替换。
  • 3 个 mockup 共享同一份 mock 数据 / IA / 文案，差异纯粹在视觉。
